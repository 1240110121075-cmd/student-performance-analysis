# Student Performance Analysis

A simple data analysis project using Python and Pandas to study how study hours, attendance, and assignment completion relate to student exam performance.

## Files
- `student_performance.csv` – sample student dataset
- `student_performance_analysis.py` – Python analysis and visualization

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis
The project calculates average study hours, attendance, and exam score, and visualizes the relationship between study hours and exam scores.

## Note
This is a small educational/demo dataset created for learning data analysis.
